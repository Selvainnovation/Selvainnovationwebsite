SELVA INNOVATION WEBSITE
=========================
Files:
- index.html
- style.css
- script.js

Run:
1. Extract the ZIP.
2. Open index.html in a browser.

Deploy:
Upload the three files to any static hosting service.

Customize:
- Change email/social links in index.html.
- Edit text, services and projects in index.html.
- Edit colors/layout in style.css.
